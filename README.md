E-commerce Landing Page - Card de Produtos

Projeto de estudos para criar uma landing page de e-commerce focada em Moda Masculina e Feminina. 
O objetivo é praticar HTML e CSS criando cards de produto responsivos com preço, desconto e link externo.

Sobre o Projeto

Esta landing page exibe uma vitrine com 3 produtos principais + seção de "Novidades" e "Destaques". 
Cada card mostra: imagem, nome do produto, preço antigo, preço com desconto, % OFF, parcelamento e frete grátis.

Funcionalidades
- **Layout com Cards**: 3 produtos em destaque na seção superior
- **Seção Novidades**: Miniaturas de produtos com links externos
- **Seção Destaques**: Produtos com galeria de 3 mini-fotos
- **Efeito Hover**: Animação ao passar o mouse nas imagens
- **Links Externos**: Botões redirecionam para Mercado Livre e Shirtshaker

Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização, Flexbox e efeitos de hover
